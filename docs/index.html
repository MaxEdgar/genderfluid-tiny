What it does

Given a name, genderfluid-tiny estimates whether it is statistically associated with feminine or masculine naming conventions. It outputs girl-associated, boy-associated, or uncertain.

This is not a gender identity classifier. It measures naming patterns learned from 102,927 real names in U.S. Social Security Administration data (1880-2020) and Census 2020 records.

Python API

from genderfluid import classify_name, is_girl_name, name_probability

classify_name("Emma")       # "girl-associated"
classify_name("James")      # "boy-associated"
classify_name("Alex")       # "uncertain"

is_girl_name("Emma")        # True
name_probability("Emma")    # 0.9731

Architecture

Input name
  |
Unicode normalization + lowercase
  |
Character n-gram extraction (2-5 grams)
  |
Hashing trick (4096-dim feature vector)
  |
Logistic regression (3 classes)
  |
Sigmoid calibration
  |
Output: girl-associated / boy-associated / uncertain

Features

Fully offline

No internet required. No data leaves your machine. No API key needed.

Tiny model

49 KB. Smaller than most profile pictures. Fits anywhere.

Fast inference

Sub-millisecond single predictions. Thousands of names per second.

Real data

Trained on 102,927 names from SSA (1880-2020) and Census 2020.

Uncertain category

Does not force binary classification. Ambiguous names get marked uncertain.

CPU only

No GPU required. Works on old hardware. No CUDA, no AVX.
