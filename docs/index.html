genderfluid-tiny

Predict gender associations from names. Fully offline. 49KB model. No API key.

$ pip install genderfluid-tiny
49 KB Model
0.9 ms Prediction
102K Names trained
0 API calls

Quick start

from genderfluid import classify_name, is_girl_name

classify_name("Emma")      # "girl-associated"
classify_name("James")     # "boy-associated"
classify_name("Alex")      # "uncertain"

is_girl_name("Emma")       # True

Or from the command line:

$ genderfluid predict Emma

Name: Emma

Girl-associated: 97.3%
Boy-associated:  0.5%
Uncertain:       2.2%

Classification: girl-associated
Confidence:     high

How it works

Extracts character n-grams from normalized names and feeds them into a logistic regression classifier trained on 102,927 real names from U.S. Social Security Administration data (1880-2020) and Census 2020.

Input name
  |
Unicode normalization + lowercase
  |
Character n-gram extraction (2-5 grams)
  |
Hashing trick (4096-dim feature vector)
  |
Logistic regression (3 classes)
  |
Sigmoid calibration
  |
Output: girl-associated / boy-associated / uncertain

The model does not determine gender identity. It estimates statistical associations between names and gendered naming conventions.

Features

Fully offline No internet. No API key. No data leaves your machine.
49 KB model Smaller than most profile pictures.
Sub-millisecond 0.93ms per prediction. 5,500 names/sec.
CPU only No GPU. No CUDA. Works on old hardware.
Uncertain category Does not force binary. Ambiguous names get flagged.
Real data 102,927 names from SSA and Census 2020.
